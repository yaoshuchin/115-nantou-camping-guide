## 📅 活動日程總覽

### 第一天（115 年 10 月 27 日 星期二）
- **07:30 - 08:00** 學校集合（921 地震公園暨南投國際會展中心園區逃生演練）
- **08:00 - 10:00** 乘車出發、安全檢查（抵達營地時實施安全檢查）
- **10:00 - 11:00** 喜相逢～環境認識（活動小隊編組、安全檢查）
- **11:00 - 12:00** 始業式～營規介紹、工作人員介紹
- **12:00 - 13:00** 午餐（中式便當）
- **13:00 - 14:00** 野營常識介紹（帳棚搭設講解、環境認識、器材使用領取）
- **14:00 - 17:00** 分站教育 Part 1：童軍技能教育
  1. 生火技巧、烹調方式
  2. 戰術偽裝、方向辨識
  3. 出神入化、繩結運用
  4. 六大毒蛇、蛇類辨識
  5. 晚會預習、音樂律動
- **17:00 - 19:00** 晚餐（炊事競賽・野炊）
- **19:10 - 21:30** 營火晚會～燭光夜語（班級節目競賽、隊輔勁歌熱舞、薪火相傳）
- **21:30 - 22:30** 盥洗、宵夜
- **22:30 - 就寢＆查舖**

### 第二天（115 年 10 月 28 日 星期三）
- **06:00 - 06:30** 起床～做個跟太陽賽跑的人
- **06:30 - 07:20** 活力有氧（早操時間）
- **07:20 - 08:00** 早餐（中式早餐・合菜）
- **08:00 - 11:30** 分站教育 Part 2：山訓、探索教育
  1. 膽量大考驗、進擊の垂降
  2. 解手結、團隊跳繩
  3. 超級蜘蛛人～攀岩絕技
  4. 生存遊戲、水彈競賽
  5. 獨木橋
- **11:30 - 14:00** 午餐（BBQ 烤肉餐）
- **14:00 - 15:00** 結訓典禮（頒獎：炊事比賽、晚會節目、晨檢、分站活動、生活教育、精神總錦標）
- **15:00 - 16:20** 平安抵校（預計 16:20 返抵南投國中）
